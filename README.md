# Локальный плеер (Android)

Нативное приложение на Kotlin + Jetpack Compose + Media3 (ExoPlayer).

## Возможности
- Папка с музыкой выбирается в «Настройках» (системный выбор папки). Приложение видит только её и вложенные папки, никаких разрешений на всё хранилище не запрашивает.
- Библиотека из 3 вкладок: **Плейлисты** (ваши), **Альбомы** (по тегам файлов), **Треки** (все вперемешку).
- Создание, переименование и удаление плейлистов, добавление и удаление треков.
- Фоновое воспроизведение, уведомление, управление с экрана блокировки и гарнитуры.
- Перемешивание, повтор (выкл. / все / один), перемотка, обложки из тегов.
- Форматы: mp3, flac, ogg/opus, m4a/aac, wav и др.

## Как получить APK

### Вариант 1: Android Studio
1. Установите Android Studio, откройте папку проекта (File → Open).
2. Дождитесь синхронизации Gradle.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Файл: `app/build/outputs/apk/debug/app-debug.apk`

### Вариант 2: GitHub Actions (без установки чего-либо)
1. Создайте репозиторий на GitHub и загрузите туда все файлы проекта.
2. Вкладка Actions → Build APK → Run workflow (или просто push в main).
3. Скачайте `LocalPlayer-debug-apk` из Artifacts, внутри `app-debug.apk`.

### Установка
Скопируйте APK на телефон, откройте и разрешите установку из неизвестных источников.

## Структура
- `Library.kt`: сканирование папки, кэш метаданных, хранение плейлистов (JSON)
- `PlaybackService.kt`: фоновый сервис воспроизведения
- `PlayerViewModel.kt`: состояние, плейлисты, управление плеером
- `Ui.kt`: все экраны
